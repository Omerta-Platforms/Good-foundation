# Progress International Group of Schools Portal

A comprehensive school management system built with Next.js, TypeScript, and Supabase.

## Features

- **Public Website**: Homepage, About, Admissions, Contact pages with responsive design
- **Authentication**: Student (Email/Password), Staff (Staff ID/Password), Admin login
- **Student Dashboard**: View profile, attendance, fees, results, download report cards
- **Teacher Dashboard**: Manage classes, upload results, edit/delete/publish results
- **Admin Dashboard**: Full CRUD operations for students, teachers, classes, subjects, results, fees
- **Result Checker**: Public result checking with admission number, session, and term
- **Dark/Light Mode**: Theme toggle with system preference detection
- **Responsive**: Mobile-first design with Tailwind CSS

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Database**: Supabase (PostgreSQL)
- **Authentication**: Supabase Auth
- **Icons**: Lucide React
- **Forms**: React Hook Form with Zod validation
- **Charts**: Chart.js / Recharts
- **Notifications**: React Hot Toast
